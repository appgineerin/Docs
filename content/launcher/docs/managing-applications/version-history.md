# Version History & Release Notes

The Versions tab of an application's detail view lists every version of that application available across all release channels, newest first. Each row shows the version number, release date, a channel badge, an optional **Required** badge, and an action button (Install / Update / Downgrade / Installed).

For a full description of the action buttons and channel-mismatch indicators, see the [Versions tab section of the Application Detail View](./application-detail.md#versions-tab).

## Opening Release Notes

Clicking any version in the Versions tab opens its release notes — a markdown-rendered page known internally as **What's New**.

<!--![Screenshot: The "What's New" release notes screen showing the version number, release date, channel badge, and a markdown-rendered changelog with headings and bullet lists.](/img/launcher/release-notes.png)-->

Release notes are downloaded on demand the first time you open them and cached locally. If the publisher has not provided release notes for a version, a placeholder message appears instead. If the download fails (for example, you are offline), an error is shown with a retry button.

Use the back arrow in the top bar to return to the Versions tab.
