# Themes & Child Applications

Some applications, such as ATVO, support child applications — for example, themes that plug into a host product. Child apps appear in the same application list as regular apps but cannot be installed without their parent.

If the parent is missing, the child appears in the **Unsupported** section with an explanation pointing you to the parent. Once the parent is installed, the child moves to the **Available** section and can be installed normally.

[Uninstalling a parent application](./per-app-settings.md#uninstall) removes its installed child apps too. The uninstall confirmation dialog lists every dependent child up front so there are no surprises.
