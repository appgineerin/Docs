# Getting Help

If you need help that this guide does not cover:

- **Discord** — The Appgineering Discord community is the fastest way to get an answer. Open the top-bar menu in the Launcher and click **Help** to go straight there.
- **Documentation** — The full Appgineering documentation lives at [docs.appgineering.com](https://docs.appgineering.com).

When asking for help, please include your Launcher version (from the [About page](./about.md)), your operating system, and a brief description of what you tried and what happened.

If your issue involves a crash or unexpected behavior, attaching the most recent log file makes diagnosis much faster — see [Sharing logs with support](./troubleshooting.md#sharing-logs-with-support).
