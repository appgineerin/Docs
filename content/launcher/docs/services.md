# Services

The **Services** tab lists Appgineering web services such as Live Timing. Services are not installed locally and do not consume disk space — they live on the web and the Launcher simply opens them in your default browser.

![Screenshot: The Services tab open, showing a list of services each with an icon, name, an Open button, and a menu button.](/img/launcher/services-tab.webp)

## Opening a Service

Click **Open** on a service row to launch it in your default browser. The Launcher does not embed a browser of its own — your operating system's default browser handles the link.

## Service Details

Each service has a menu button (the three-dot icon) that exposes an **About** option. The About page shows a markdown-rendered description of the service and any relevant links such as documentation or pricing.

![Screenshot: The About page for the Live Timing service, with the service icon, description text, and a "Visit Website" link button.](/img/launcher/service-about.webp)

Use the back arrow in the top bar to return to the Services list.
